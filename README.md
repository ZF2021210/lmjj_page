# LMJJ 网页版

穆祉丞 × 王橹杰 追星相册网页版（纯 HTML/CSS/JS，无后端）。功能对齐 Android/iOS 版：相册、走马灯（花瓣 + 音乐列表循环）、倒计时、设置。

## 特点
- 纯前端，数据存浏览器本地（IndexedDB 存照片/音乐，localStorage 存设置/倒计时），**不上传任何服务器**。
- **已打包 21 张照片（`img/`）+ 8 首音乐（`music/`）**：首次打开即可见相册、走马灯自动播音乐，无需再导入；仍可点「+ 导入」追加自己的图/音。
- **CSS/JS 已内联进 `index.html`**：单文件自包含，手机浏览器（Safari / Chrome）直接打开就有完整样式与交互，不再依赖外部 css/js 文件加载。
- 蓝粉应援色主题，移动端优先布局。

## 本地运行
直接用浏览器打开 `index.html` 即可。打包的照片/音乐用相对路径加载，`file://` 双击打开就能看图听歌。仅「+ 导入」功能在个别浏览器的 `file://` 下可能受限（本地存储被禁），那时可起本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 打包发送给对方（离线压缩包）
1. 把 `index.html` + `img/` + `music/` 压缩成 zip（`index.html` 已内联全部样式与逻辑，无需其它文件）。
2. 把 zip 发给对方（微信 / 邮件 / 网盘均可）。
3. 对方解压后**双击 `index.html`**，浏览器里即可看相册、走马灯配乐——**无需联网、无需安装任何东西**。
4. 想像 App 一样用：iPhone Safari 打开后点底部「分享 → 添加到主屏幕」，桌面就有图标了。
5. 走马灯音乐控制：底栏有「上一首 ⏮ / 播放暂停 ▶ / 停止 ⏹ / 下一首 ⏭」四个按钮。

## 部署到 GitHub Pages（⚠️ 须 Private 仓库）
1. 在 GitHub 新建仓库——**因已打包明星照片/音乐，务必设为 Private**（公开仓库存在肖像权/版权风险；Private 仓库启用 Pages 需 GitHub Pro）。
2. 把 `index.html`、`style.css`、`app.js`、`img/`、`music/` 全部上传到仓库根目录。
3. 仓库 Settings → Pages → Source 选 `main` 分支 `/root` → Save。
4. 等待几分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

## 功能对照（Android 版基线）
- 相册：全部/穆/橹/LM 三 chip 筛选；点图全屏可收藏/改分类/分享/删除/转走马灯。
- 走马灯：自动轮播（间隔可调）+ 6 形状蓝粉花瓣 + 音乐列表循环。
- 我的：照片管理 / 音乐管理 / 倒计时 / 设置（花瓣开关、走马灯间隔、CP 纪念日）。
- 倒计时：增/改/删，选日期时间 + emoji。

## 通知说明（网页版硬限制）
网页通知受浏览器限制，**仅在页面打开时生效**。到点的倒计时会显示页内横幅；如需系统通知会请求授权。**关闭页面后无法保证提醒**——这是用网页替代原生 App 的固有取舍。

## 数据与隐私
- 所有数据仅存在你的浏览器本地，清除浏览器数据会丢失导入内容。
- 换设备/换浏览器需重新导入照片与音乐。
- 分类规则与 Android 一致：文件名含「王橹杰/WLJ/橹」→橹；含「穆祉丞/MZC/穆」→穆；两者→LM；否则默认 LM。导入后可在全屏图里点 🏷️ 手动改分类。
